# Biovoxis · Home (página de referência)

Protótipo da nova home do biovoxis.com, gerado a partir do KV (`KV-HOME-BIOVOXIS.md`).
HTML + CSS + JS estáticos, sem build. Publicado via Netlify (deploy contínuo a partir da branch `main`).

- `index.html`: todas as seções da home
- `css/style.css`: tokens e layout
- `js/main.js`: abas de planos, menu mobile e animações de scroll (GSAP + ScrollTrigger via CDN)

> Página com `noindex`: é referência, não o site oficial.
